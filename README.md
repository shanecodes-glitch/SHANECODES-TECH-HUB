## 📥 **How to Use**

### **Option 1: Download from Website**
1. Visit [ShaneCodes Tech Hub](https://shanecodes-glitch.github.io/shanecodes-tech-hub)
2. Browse the tool collection
3. Click **Download** on any tool
4. Save the `.ps1` file
5. **Right-click** → **Run with PowerShell** (as Administrator)

```bash
