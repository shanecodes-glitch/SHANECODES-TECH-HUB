📋 About This Project
ShaneCodes Tech Hub is a curated collection of PowerShell tools designed to help Windows users diagnose, repair, and optimize their systems. Each tool is crafted with precision, tested for reliability, and offered completely free.

🎯 Mission
"Empowering users with powerful Windows tools that are accessible, reliable, and completely free."

🛠️ Tool Collection
#	Tool Name	Category	Description
1	Smart PC Optimizer	Repair	Auto-detects and fixes 20+ PC issues
2	ShaneCodes Cleaner	Utility	Deep clean with animated progress bar
3	Quick Fix Wizard	Repair	One-click fixes for common problems
4	System Restore Manager	Utility	Create, manage, and restore restore points
5	Boot Speed Analyzer	Diagnostic	Measures boot time and provides optimization tips
6	Privacy Guard	Security	Clears browsing history, cookies, and temp files
